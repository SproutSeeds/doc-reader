Read Docs 0.7.1 improves first-run setup so a new user can finish without a personal walkthrough.

- Speech prepares automatically. Try again also works when an older installation disabled background model loading.
- Setup includes microphone selection and concise help for the current step. On Mac, Allow registers Read Docs for Accessibility before opening System Settings.
- The keyboard diagram and dictation/read-aloud instructions follow the keys you choose. Back and Continue remain visible in small windows.
- A dedicated desktop guide covers installation, permissions and common recovery steps without developer setup instructions.

The downloads include the speech runtime and models. Apple silicon and Intel Mac packages are signed and Apple-notarized. Windows remains an unsigned preview.

Automated checks cover model preparation, actual offline speech, packaged windows, installer startup and setup behavior. The final setup trial still asks users to confirm their own microphone, playback and shortcuts.
