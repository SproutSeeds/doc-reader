# Read Docs

[Download](https://frg.earth/read-docs) · [Source](https://github.com/SproutSeeds/doc-reader)

## Install

Choose Apple silicon, Intel Mac or Windows on the download page. On Mac, open
the DMG and drag Read Docs into Applications, then open it there. To identify
your Mac, open About This Mac: Apple M-series chips use Apple silicon; an Intel
processor uses Intel Mac. On Windows, run the Setup EXE and choose Open Read Docs.

Mac requires macOS 13 or later. Windows requires 64-bit Windows 10 or 11 on an
Intel or AMD PC. The Windows preview is unsigned, so Windows may show an
unknown-publisher warning. Follow your computer's security policy; the Mac
downloads are signed and Apple-notarized.

The app includes the speech engines, English reading voices and multilingual
dictation model. No terminal, developer tools, account or API key is needed.
English reading and dictation work offline.

## Set up

1. **Speech:** wait for both engines to say Ready. First launch can take a minute.
2. **Access:** choose Allow. On Mac, enable Read Docs under Microphone,
   Accessibility and Input Monitoring in System Settings. On Windows, enable
   microphone access for desktop apps. Choose your microphone in this step.
3. **Shortcuts:** keep the recommendations or choose alternatives from the lists.
4. **Try it:** listen to the sample, dictate into the text box, then highlight
   the result and use your reading shortcut. Confirm each check when it works.

If macOS requests a restart after changing permissions, quit and reopen the
app. Setup resumes where you left off. Back returns to the previous step;
Set up later lets you continue another time. Reopen setup from Settings.

## Use

With the recommended keys, hold Left Option on Mac or Left Alt on Windows while
speaking. Release to insert your words into the focused text field. On Mac, a
quick tap also starts recording; tap the same key again to stop.

Highlight text and tap Right Command on Mac or Right Windows on Windows to
hear it. If your keyboard has no right Windows key, choose Ctrl + Alt + R in
setup. Settings contains the same presets and additional supported custom keys.
Avoid shortcuts already used by your other apps.

## If something needs attention

- **Speech stays on Preparing:** choose Try again. If it still cannot start,
  quit and reopen the app. The desktop download already includes the models.
- **No dictation:** check microphone access, choose the correct input in Access,
  and click the text field before using your shortcut.
- **Words stay in the clipboard:** on Mac, allow Accessibility so Read Docs can
  paste into the active app. Some protected fields do not accept automation.
- **Reading does not start:** finish dictation first, select the text again,
  and check your shortcut and output volume.
- **No audio from the sample:** check the computer's selected speaker/headphones
  and volume, then try Listen again.

For a reproducible problem, [report an issue](https://github.com/SproutSeeds/doc-reader/issues)
with the app version, operating system and setup step. Keep private document
text and recordings out of the report.
