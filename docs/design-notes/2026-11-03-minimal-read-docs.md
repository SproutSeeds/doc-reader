# Read Docs app: a quiet reading canvas

The download page established a restrained mineral palette, expressive italic type and plain text controls. The app carries that character into a useful reading space.

Considered three compositions: a permanent library rail with a narrower reader; a full-screen editor with corner controls; and a centered reading measure with a compact glass playback surface. Chose the third to remove persistent navigation and settings without hiding the current text or playback state. The app stays a workspace rather than repeating the landing page composition.

Use system serif type for reading and the Read action, with system sans-serif for controls. No remote fonts or network assets. The canvas stays flat; glass groups the playback controls and modal panels. Links, navigation, previews, Copy, Edit and Close are text, without arrows or ornamental icons.

Library, Import, Voice, Speed and Settings open on demand. Native modal dialogs provide keyboard focus containment and an inert background; each has a visible Close control and Escape support. Settings groups dictation, shortcuts and diagnostics in explicit disclosures. Keep transcription review conditions, active recording, progress and failures visible. Keep the existing local speech models, API contracts, library format and draft storage keys.

Scope: shared Mac/Windows web workspace and visible app identity. Native bundle identifiers and existing user data paths remain stable. Browser checks use an isolated sample library; they do not establish physical microphone, global hotkey or speech-quality acceptance.
